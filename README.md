An entry for the make.fun bounty "Unsent: The Micro-Confession Sprint". The program writes one two-part micro-confession to /output/entry.txt: a To: line naming who the message was meant for, and the unsent message itself — one line written exactly as it was typed, with no explanation after it. The writer validates the text against the bounty gate (1–260 characters total, message at most 200) before writing it.

## Run it

```sh
python3 main.py
```
